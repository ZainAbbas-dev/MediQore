# IEC application (P0-9)

LI-10: "No real patient data will be collected or processed until IEC approval is obtained from COMSATS University Islamabad's Institutional Ethical Committee, to be submitted in Semester 7." The Phase 0 exit gate includes "IEC application submitted".

This folder holds a **draft**. Submitting it is a human task: the committee's own form, signatures and dates have to come from the team and the supervisor.

## Files

| File | What it is |
|---|---|
| [`application-draft.md`](application-draft.md) | The application text, section by section. Copy it into the committee's official form. |
| [`participant-information-sheet.md`](participant-information-sheet.md) | What participants are told. Needs an Urdu version. |
| [`consent-form.md`](consent-form.md) | Consent form. Needs an Urdu version. |
| [`usability-protocol.md`](usability-protocol.md) | The session plan: tasks, observation sheet, questionnaire outline. |

Text in **[square brackets]** is a placeholder to fill in. **[Decide]** marks a choice the team has to make; the drafts give the options.

## Checklist to submit

- [ ] Get the current IEC application form and guidelines from the department or the committee secretary. Map each section of `application-draft.md` onto it.
- [ ] Decide every **[Decide]** item, especially:
  - whether the application covers only the usability check (as drafted) or also future field data;
  - the district and the permission letter;
  - the number of participants;
  - a female facilitator;
  - any recording.
- [ ] Have the participant information sheet and consent form translated into Urdu by a team member, and checked by a second Urdu reader.
- [ ] Get the supervisor's review and signature.
- [ ] Ask the District Health Authority or the LHW Programme office for a permission letter to approach LHWs, if the committee needs it with the application.
- [ ] Submit. Record the date and reference number in the Phase 0 issue (P0-9) and in this README.
- [ ] When the decision arrives, record it here. Until then, the Phase 4 usability check runs with peers on dummy data (roadmap, week 26).

## Data rule

This repository is public. **Nothing collected from participants goes into it**: no consent forms, names, notes, questionnaire answers, photos or recordings. Section 9 of the draft says where that data is kept. Only an anonymised summary may appear in the final report.
